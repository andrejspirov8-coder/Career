12.0)\n   - Controls acceptance threshold at global level\n   - Can be overridden per tier\n\n2. matching.require_clear_winner (default false)\n   - Forces confidence=clear_winner (margin must be high)\n   - Can be overridden per tier\n\n3. matching.require_recruiter_gate (default true)\n   - Must pass hiring_gate_ok (see DEFAULT_GATE_TERMS)\n   - Can be overridden per tier\n\n4. matching.require_sector_and_cv_agreement (default true)\n   - Stricter gate: must show industry signal + CV score floor\n   - Uses cv_min_scores per variant\n\n5. recruiter_matching.sector_beats_cv_min_score (default 6.0)\n   - Threshold for sector score to override CV match\n   - Higher = favor CV matching; lower = favor sector signals\n\n6. recruiter_matching.sector_keywords\n   - Maps variant → phrases that trigger sector signals\n   - Sector score = count of matching phrases × 3.0 (uncapped)\n\n7. recruiter_matching.outreach_exclude_terms\n   - Blacklist: profiles containing these terms are skipped\n   - Examples: \"staffing agency\", \"pharma\", \"banking\"\n\n8. tiers.tier_*.min_primary_score, min_margin_over_second, company_signals_any\n   - Per-tier overrides for score thresholds\n   - company_signals_any: if set, requires substring match in profile text\n\nCRITICAL FLOW CONTROLS\n======================\n\nA profile enters the pipeline and must pass these gates (in order):\n\n1. Search query execution (cmd_scout)\n   → Skipped if: profile not found by LinkedIn search\n\n2. Profile scrape (linkedin_recruiter_bot.py)\n   → Skipped if: CAPTCHA, unusual activity, login wall, page error\n\n3. Deduplication check\n   → Skipped if: canonical_profile_url already in recruiters.csv (seen before)\n   → Skipped if: canonical_profile_url in skip_revisit_urls (no_connect status)\n\n4. Matching gate (should_send_recruiter_connection)\n   → Skipped if: min_primary_score not met\n   → Skipped if: sales_only_no_hiring (pure sales, no HR/hiring signal)\n   → Skipped if: require_recruiter_gate=true and no hiring_gate_ok\n   → Skipped if: require_sector_and_cv_agreement=true and not aligned\n   → Skipped if: profile_negative_hits (variant negative keywords found)\n\n5. Tier assignment (assign_best_tier)\n   → Assigned to tier_rest (backlog) if: no tier rule threshold met\n   → Assigned to specific tier if: all tier rule gates pass\n\n6. Session filtering (build_session_queue_payload)\n   → Excluded if: tier_filter set and profile tier != requested tier\n   → Excluded if: profile_url in skip_revisit_urls (per-tier skip)\n\n7. Dispatch safety (cmd_dispatch)\n   → Blocked if: --allow-live-dispatch not set (dry-run only)\n   → Blocked if: recruiter_approval.require_approvals(invite_notes) fails\n      (SQLite ledger entry missing or note hash mismatch)\n\n8. Daily cap enforcement (linkedin_recruiter_bot.effective_daily_invite_cap)\n   → Stopped if: sent count today >= max_connections_per_day\n   → Reduced if: accept_rate < min_accept_rate_for_full_cap\n      (pacemaker uses low_cap instead)\n\nDATA FLOW SUMMARY\n=================\n\nconfig.yaml\n    ↓\nrecruiter_orchestrate.py (CLI entry)\n    ↓\n┌── cmd_scout ──→ linkedin_recruiter_bot (search + scrape)\n│                 ↓\n│            Playwright browser\n│            ├─ LinkedIn People search\n│            ├─ Profile page navigation\n│            └─ JS injection for about/role_text\n│                 ↓\n│            recruiter_match.match_recruiter_profile()\n│                 ↓\n│            ACTION_PLAN_JSONL ← Scout rows (scored, but not yet planned)\n│\n├── cmd_plan ──→ build_session_queue_payload()\n│                 ↓\n│            Reads ACTION_PLAN_JSONL\n│            Filters by tier + skip_revisit\n│            Builds dispatch queue\n│                 ↓\n│            SESSION_STATE_JSON ← Session document (ready for dispatch)\n│\n└── cmd_dispatch ──→ linkedin_recruiter_bot (send connections)\n                    ↓\n                Reads SESSION_STATE_JSON\n                For each profile in queue:\n                ├─ Check recruiter_approval ledger\n                ├─ Send connection request (if not dry-run)\n                └─ Log status to recruiters.csv\n                    ↓\n                recruiters.csv ← Audit log (all actions)"
