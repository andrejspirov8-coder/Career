# Architecture-modernization archive

These files were moved out of active locations on 16 July 2026 without
changing or deleting their historical content.

- `root-reports/` contains old execution and health snapshots.
- `search-reports/` contains dated, point-in-time job-search results.
- `implementation-prototypes/` contains superseded prototypes and rollout
  notes whose implemented versions now live in active modules.
- `legacy-automation/` contains the obsolete secondary Makefile and full-cycle
  shell runner.
- `dependency-snapshots/` contains the retired pip requirement lists;
  `pyproject.toml` and `uv.lock` are the only current dependency sources.
- `cv-reviews/` contains completed point-in-time CV reviews.

This directory is reference-only and is excluded from operational checks.
